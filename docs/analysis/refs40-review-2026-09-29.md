## Remaining defect and correction

The new regression reproduced the URL defect with an actual LF before the URL:
the parsed title was `IBM Maximo Application Suite.` rather than
`IBM Maximo Application Suite`. The original fixture used Rust's escaped source
line continuation, so it exercised a space, not a newline.

`title_end` now recognizes whitespace after sentence punctuation rather than
only an ASCII space, and skips that separator without assuming a one-byte
character. `title_goes_on` checks the entire leading whitespace separator for
the masked identifier gap before considering lowercase continuation text.

Coverage includes space, LF, CRLF, tab and nonbreaking space. A negative control
preserves genuine lowercase title continuations across those same separators.
The IEEE regression now asserts the complete title and separate venue, and
four supported quote pairs are tested with multiple commas inside the title.
