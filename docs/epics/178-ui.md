## Implemented / tested
- `web/app/workspace.tsx` + `globals.css`: one composer and Add menu; content/URL detection, per-item queue/progress/cancel/retry, folders/paste/drop, system light/dark mode, wrapped sans text and 48px controls. Diagnostic evidence is secondary.
- URL/history selection and scroll restoration; per-owner IndexedDB recovery. Saved original/result bytes are authoritative in R2/D1; local snapshots drop originals once saved. Interrupted jobs reopen owned originals.
- Parsed text is visible before image retention completes. Reader images are restricted to the selected document's private media/assets.
- `scripts/test-web-workspace.cjs` exercises actual React components with JSDOM and mocked network/storage. It covers independent failures, MIME dispatch, ownership of retries, Back/scroll/reload, image restrictions and cancellation.
- Final reader sanitization rejects style/form/input/background-based injection; raw saved HTML is treated as untrusted.
