# Batch 4 contract: workbench tracks as workspace crates (each in its own git worktree and PR)

Same HARD RULES as CONTRACT.md (no cargo/rustc/compilers, no network, no git; touch only files inside YOUR crate directory unless your section says otherwise;
clippy pedantic + rustfmt clean; offline crate sources in scratchpad/crates/ (ureq-3.4.2, rusqlite-0.40.2, serde/regex are standard; plus gpui-0.2.2, kokoro-tts-0.3.3,
usearch-2.26.2, fastembed-7.1.0, objc2-av-foundation-0.3.2, docling-asr-1.69.2, docling-core-1.69.2); API docs saved as HTML in scratchpad/docs/ (zotero_api_basics.html, zotero_api_write.html,
openalex_search.html, crossref.html, s2.html)). The repo root is a Cargo workspace: `members = [".", "crates/*"]`, `[workspace.package] edition = "2024", license = "MIT"`,
`[workspace.lints.clippy] pedantic = warn`. Every new crate: `crates/<name>/Cargo.toml` with `edition.workspace = true`, `license.workspace = true`, `[lints] workspace = true`,
and `crates/<name>/src/lib.rs` starting with a crate doc comment and `#![allow(clippy::must_use_candidate, clippy::module_name_repetitions, clippy::missing_errors_doc)]`.
Shared types: crate `tpe-common` (crates/tpe-common): `PaperRecord{title, authors, year, venue, doi, arxiv_id, pmid, pmcid, url, abstract_text, source, source_id}`, `normalize_doi`, `normalize_arxiv_id`.
Depend on it with `tpe-common = { path = "../tpe-common" }`.

Global product rules: no network in tests (record fixtures as JSON strings in tests); no secrets in code, logs, argv or SQLite plaintext; every public fn documented; every claim in your
final report must point at a test name or a source line. CI runs `cargo clippy --workspace --all-targets -- -D warnings` and `cargo test --workspace` on Linux x86-64, Linux arm64 and macOS arm64:
anything macOS-only must be behind `#[cfg(target_os = "macos")]` with a compiling non-macOS fallback (an error value), and anything needing model files must skip cleanly when they are absent.

## T1 tpe-credentials (Opus) — crates/tpe-credentials
Trait `CredentialStore { fn get(&self, service: &str, account: &str) -> Result<Option<Secret>, CredError>; fn set(&self, service, account, secret: &Secret) -> Result<(), CredError>; fn delete(..); fn list(&self, service) -> Result<Vec<String>, CredError> }`
`Secret(String)` with a Debug impl that prints `Secret(***)` and `Drop` zeroising (overwrite bytes; `zeroize` crate is allowed: `zeroize = "1"`).
Backends: `KeychainStore` (macOS only; `security-framework = "3"` with `security-framework::passwords::{get_generic_password, set_generic_password, delete_generic_password}`; on other OSes construction returns `CredError::Unavailable`),
`EncryptedFileStore` (all OSes; JSON map encrypted with XChaCha20-Poly1305 via `chacha20poly1305 = "0.10"` and a key derived with `argon2 = "0.5"` from a passphrase provided by the caller; file mode 0600 on unix; atomic write).
`CookieJarStore`: persist per-host cookies (`Cookie{name,value,domain,path,expires_unix:Option<i64>,secure,http_only}`) as a Secret under service "cookies", account = host; helper `fn cookie_header(&self, host) -> Option<String>` (drops expired).
`ApiKeys` helper with well-known service names as consts: OPENALEX, CROSSREF_MAILTO, SEMANTIC_SCHOLAR, NCBI (PMC/E-utilities api key), EUROPE_PMC, ZOTERO, ANTHROPIC, OPENAI, LIBRARY_PROXY.
Tests: encrypted file store round trip in a tempdir, wrong passphrase fails, delete/list, cookie expiry filtering, Secret debug redaction. Keychain test only on macOS and only when env `TPE_KEYCHAIN_TESTS=1`.

## T2 tpe-biblio (Opus) — crates/tpe-biblio : scholarly metadata + full-text location clients
`ureq = "3"` + `serde_json`. A `Client { agent: ureq::Agent, user_agent, mailto: Option<String>, keys: HashMap<&'static str, String> }` with rate limiting (min interval per host, `std::time::Instant`) and `offline: bool` (any request → `BiblioError::Offline`).
Modules, each with `fn parse_<x>(json: &str) -> Result<Vec<PaperRecord>, BiblioError>` PURE functions tested on recorded JSON snippets (write realistic 1–2 result snippets yourself from the saved API docs), and a thin `fetch_*` wrapper that does the HTTP call:
 - `openalex`: `GET https://api.openalex.org/works?search=<q>&per-page=<n>&mailto=<m>`; `works/https://doi.org/<doi>`; map display_name, authorships[].author.display_name, publication_year, primary_location.source.display_name, doi (strip prefix), ids.pmid/pmcid, open_access.oa_url, abstract_inverted_index → abstract (reconstruct by position).
 - `crossref`: `GET https://api.crossref.org/works?query=<q>&rows=<n>&mailto=<m>` and `works/<doi>`; message.items[].title[0], author[].given/family, issued.date-parts, container-title[0], DOI, URL, link[] (application/pdf) → pdf candidates.
 - `semantic_scholar`: `GET https://api.semanticscholar.org/graph/v1/paper/search?query=<q>&fields=title,authors,year,venue,externalIds,openAccessPdf,abstract` (x-api-key header when present).
 - `pmc`: NCBI E-utilities `esearch.fcgi?db=pmc&term=<q>&retmode=json` + `esummary.fcgi?db=pmc&id=<ids>&retmode=json` (api_key param when present); Europe PMC `https://www.ebi.ac.uk/europepmc/webservices/rest/search?query=<q>&format=json&resultType=core` (pmid, pmcid, doi, title, authorString, journalTitle, pubYear, fullTextUrlList).
 - `openurl`: build an OpenURL 1.0 link-resolver query (`rft.doi`, `rft.title`, `rft.au`, `rft.date`) for a configured base URL (library link resolver), and `unpaywall` lookup `https://api.unpaywall.org/v2/<doi>?email=<m>` → best_oa_location.url_for_pdf.
 - `resolve`: `fn locate_fulltext(&self, rec: &PaperRecord) -> Vec<FullTextCandidate{url, source, kind: "pdf"|"landing", requires_session: bool}>` combining Unpaywall, OpenAlex oa_url, Crossref links, PMC (https://www.ncbi.nlm.nih.gov/pmc/articles/<pmcid>/pdf), arXiv (https://arxiv.org/pdf/<id>), publisher via the link resolver (requires_session true).
 - `dedupe`: merge records from several sources by DOI, else arXiv id, else normalised title+year; keep the union of fields with source precedence crossref > openalex > s2 > pmc.
Google Scholar has NO public API and its ToS forbid scraping: provide only `fn scholar_search_url(q) -> String` for the browser track, documented as such.
Tests: each parser on recorded JSON, abstract reconstruction, dedupe precedence, OpenURL building, offline client errors without network, rate limiter spacing (mocked clock via a `now: fn() -> Instant` field).

## T4 tpe-search (Opus) — crates/tpe-search : semantic + lexical search over extracted text
Index over `tpe`'s ledger (read-only rusqlite on the ledger file: tables pages(run_id,page,text), runs(hash,...), metadata(title,doi...)): `Chunker` (≈ 200-word windows with 40-word overlap, sentence-aware split on `.!?` followed by space+capital), `Chunk{doc_hash, run_id, page, idx, text}`.
Lexical: SQLite FTS5 (rusqlite feature `bundled` includes FTS5) in a separate index DB `search.sqlite`: `chunks_fts(text, doc_hash UNINDEXED, page UNINDEXED, idx UNINDEXED)` with bm25 ranking and snippet().
Semantic: trait `Embedder { fn dim(&self) -> usize; fn embed(&self, texts: &[&str]) -> Result<Vec<Vec<f32>>, SearchError> }` with two impls: `HashEmbedder` (deterministic feature hashing of word uni+bigrams into 256 dims, L2-normalised; always available, used in tests) and `OnnxEmbedder` behind feature `onnx` using `fastembed = "7"` (default model BGE-small-en-v1.5; read scratchpad/crates/fastembed-7.1.0/src for `TextEmbedding::try_new(InitOptions...)`, `embed(Vec<&str>, batch)`; models download on first use — in this crate expose `OnnxEmbedder::from_cache_dir(path)` and document `FASTEMBED_CACHE_PATH`), and gate model-requiring tests on the file being present.
Vector store: `usearch = "2"` behind feature `usearch` (read scratchpad/crates/usearch-2.26.2/rust/lib.rs: `Index::new(&IndexOptions{dimensions, metric: MetricKind::Cos, quantization: ScalarKind::F32, ..})`, `reserve`, `add(key, &[f32])`, `search(&[f32], k)`, `save/load/view`), plus a default `FlatStore` (brute-force cosine over a `Vec<(u64, Vec<f32>)>` persisted as a compact binary file) so the crate works without usearch.
API: `SearchIndex::open(dir) `, `index_ledger(&mut self, ledger_path, embedder) -> IndexStats`, `search(&self, query, k, mode: Lexical|Semantic|Hybrid{alpha}) -> Vec<Hit{doc_hash, page, idx, score, snippet, title, doi}>` (hybrid = reciprocal rank fusion), `stats()`.
CLI bin `tpe-search` (clap): `index --ledger <f> --index <dir> [--embedder hash|onnx]`, `query --index <dir> --k 10 --mode hybrid "<text>"`.
Tests: chunker boundaries/overlap, hash embedder determinism + cosine sanity, FlatStore top-k, FTS5 bm25 on a tiny in-memory ledger built with the real `tpe` ledger schema (copy the CREATE TABLE statements for pages/runs/metadata/documents into the test), RRF fusion ordering, end-to-end index+query on 3 synthetic docs.

## T5 tpe-speech (Opus) — crates/tpe-speech : neural TTS on macOS validated by docling ASR
Two engines behind a trait `Tts { fn synthesize(&self, text: &str, voice: &str) -> Result<Audio{sample_rate: u32, samples: Vec<f32>}, SpeechError> }`:
 - `AvSpeech` (macOS only, `objc2-av-foundation = "0.3"` + `objc2 = "0.6"` + `objc2-foundation`): `AVSpeechSynthesizer` with `writeUtterance:toBufferCallback:` to capture PCM into `Audio` instead of playing (read the offline objc2-av-foundation source for method names: AVSpeechSynthesizer::writeUtterance_toBufferCallback, AVSpeechUtterance::speechUtteranceWithString, AVSpeechSynthesisVoice::speechVoices / voiceWithIdentifier; premium/enhanced voices are quality `AVSpeechSynthesisVoiceQuality::Premium`), list voices with quality; when the API surface is uncertain, isolate the unsafe FFI in one small module with a clear `// verified against objc2-av-foundation-0.3.2/src/generated/AVSpeechSynthesis.rs:<line>` comment on each call.
 - `Kokoro` (all OSes, feature `kokoro`, `kokoro-tts = "0.3"`: read scratchpad/crates/kokoro-tts-0.3.3 for `KokoroTts::new(model_path, voices_path)`, `Voice`, `synth`/`stream` and its runtime deps): model files kokoro-v1.0.int8.onnx (108 MB) + voices-v1.0.bin (26 MB) from https://github.com/thewh1teagle/kokoro-onnx/releases/download/model-files-v1.1/ — resolved via env `TPE_KOKORO_DIR`; tests skip when absent.
 - `wav::write(path, &Audio)` 16-bit PCM WAV; `resample_to_16k(&Audio) -> Audio` (linear) because Whisper wants 16 kHz mono.
 - `validate::round_trip(tts: &dyn Tts, text, voice) -> Result<RoundTrip{transcript, word_error_rate: f32, audio_secs: f32}, SpeechError>`: synthesize → WAV bytes → `docling_asr::transcribe_with_options(...)` (read scratchpad/crates/docling-asr-1.69.2/src/lib.rs for the exact fn and which audio formats/sample rates it accepts, and which model files it needs: `.models/asr/{encoder_model,decoder_model}.onnx` + vocab, from the docling models-v1 release) → WER against the input text (normalised: lowercase, alnum, collapse spaces). `docling-asr = { version = "1.69", optional = true }` behind feature `asr`. Ben's rule: if the transcript is empty, the TTS FAILED (return `SpeechError::SilentOutput`).
 - `play::play(&Audio)` on macOS via AVAudioPlayer from a temp WAV (objc2-av-foundation), error elsewhere.
 - CLI bin `tpe-speak`: `voices`, `say --voice <id> --out out.wav "<text>"`, `check --voice <id> "<text>"` (round trip; prints WER; exit nonzero when WER > 0.3 or silent).
Tests: WAV header bytes, resampler length/ratio, WER function (exact, one substitution, empty transcript → error), engine listing compiles on Linux with `SpeechError::Unsupported`. macOS/asr/kokoro tests skip cleanly when unavailable (`eprintln!("skipped: …")`).
